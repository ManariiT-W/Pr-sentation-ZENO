# ZENO — Prototype cinéma

Extraire entièrement l’archive, puis ouvrir **index.html** dans le dossier ZENO_Prototype_Cinema. Garder les dossiers css, js et assets à côté du fichier. Le prototype fonctionne sans installation et sans connexion Internet.

Ce prototype présente les scènes **1, 5 et 9**, conformément à la mission de validation avant extension aux dix scènes. Les numéros affichés conservent leur place dans la présentation complète.

## Commandes

- Flèches gauche/droite ou boutons : changer de scène.
- Onglets 01, 05 et 09 : accès direct.
- Mode performance : réduire les animations.
- Plein écran : bouton dédié ; F11 si le navigateur refuse la demande.

La composition en 16:9 s’ajuste à la fenêtre. La préférence système de réduction des animations est prise en compte.

## Fichiers

- index.html : contenu des trois scènes.
- css et js : présentation, transitions et navigation.
- assets : sculpture, logos et polices locales avec licences.
- reference/index_valide.html : sauvegarde intégrale des dix diapositives précédentes.
- reference/contenu_valide.json : inventaire des dix diapositives.
- controle : conservation et bilan des vérifications.

## Validation attendue

Valider la sculpture inspirée du portrait, la direction artistique et la lisibilité sur l’écran de projection avant la déclinaison sur les dix scènes. Le rendu visuel et la fluidité réelle n’ont pas pu être contrôlés dans cet environnement.

La présentation complète de référence est distincte du prototype ; ses éventuelles dépendances externes n’affectent pas le prototype autonome.
