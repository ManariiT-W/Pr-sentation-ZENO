# Intentions des images dérivées

Méthode : génération intégrée d’images avec références locales, sans API externe du projet.

Instruction commune : rendu publicitaire cinématographique réaliste cohérent avec les planches, préserver visage, coiffure, silhouette et vêtements ; noir profond, contours dorés chauds, aucun bleu/cyan/violet, aucun texte ajouté, aucune personne supplémentaire, format paysage 16:9.

- open.png : ZENO seul au centre, haut du corps, bras ouverts et paumes visibles, espace libre entre les mains pour intégrer ensuite le vrai logo ; lumière au-dessus des épaules, visage partiellement dans l’ombre.
- handshake.png : ZENO à gauche et client à droite selon leurs deux planches, poignée de main professionnelle, mains et torses prioritaires, anatomie correcte, costumes fidèles, fond noir.
- thinking.png : ZENO seul dans le tiers gauche, trois-quarts orienté à droite, main près du menton, posture réfléchie, espace sombre pour les statistiques.
- conversation.png : ZENO et client au centre, cadrage à la taille, échange professionnel calme, petit geste explicatif et écoute, aucun dialogue écrit, bas de l’image fondu dans le noir.
- pov.png : vue subjective, seul l’avant-bras droit de ZENO et sa main ouverte entrent dans le quart inférieur droit, manche noire et détails dorés, reste de la scène noir.

Le logo officiel n’est pas généré : il est intégré séparément à partir du fichier fourni. Manarii utilise directement la planche officielle, cadrée par la mise en page.
